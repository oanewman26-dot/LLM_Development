Architecture Decisions Locked In
StateEncoder runs once per forward pass, not per block. The compressed state_latent is broadcast to every TransformerBlock. More efficient and keeps the 171→16 compression in one place.
Zero-init baseline property holds exactly. state_head, routing_head, and StateConditioner output projections all initialise to zero. At step 0, aurora_state=None and aurora_state=random produce identical logits. Verified.
StateConditioner is unignorable. It multiplies every hidden state in every block after RMSNorm. Unlike prompt text, the network cannot route around it.
CONTROL_PILOT config exists. Same architecture, state_size=0, no state encoder created. True control model for A/B experiments.
