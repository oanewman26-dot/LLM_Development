# Security and privacy

## Supported versions

AuroraLM is a research prototype without a production support guarantee.
Security and privacy reports should target the current default branch.

## Reporting a vulnerability

Use this repository's Security tab to open a private vulnerability report when
that channel is available. Otherwise, first contact the maintainer through
their GitHub profile without including exploit details. Do not disclose
credentials, private Aurora material, or other sensitive data in a public
issue.

Include the affected revision, a minimal reproduction, expected impact, and
any suggested mitigation. Reports will be assessed on a best-effort basis.

## Data boundary

Private Aurora records, journals, full training corpora, credentials and model
checkpoints are outside the intended public repository scope. Generated
receipts should contain aggregate evidence or digests rather than raw private
source material.
